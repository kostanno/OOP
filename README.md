# Проект ДЗ
## Описание:
Создал модуль, для работы  с классами, а также сделали тесты

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/kostanno/OOP.git
```
2. Установите зависимости:
```
poetry install
```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Проверьте домашние задание.
